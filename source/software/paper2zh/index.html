界面示意

BUILT FOR READING

把翻译放回阅读路径。

先阅读原文，再按需要翻译指定页或全文。翻译完成后继续用同一个工作区整理和标记，减少在多个窗口之间来回切换。

01

尽量保留版式

公式、图形与页面结构尽量保留，适合在上下文中理解论文。复杂页面的换行和局部排版仍可能变化。

02

原译对照连续阅读

原文与中文译文在同一阅读路径中切换。支持缩放、翻页和抓手移动，阅读节奏由你掌握。

03

缩放与批注

选中文字添加高亮或下划线，批注保存在本机，便于之后复读。

04

本地文献库

用嵌套文件夹整理论文，内容去重，建立属于自己的本地阅读库。

05

原文、中文 MD 与索引

翻译后自动整理原文与中文 Markdown，并生成 agent 索引，方便继续检索、总结和接入自己的工作流。

06

自配 API，查看用量

支持配置 DeepSeek 或兼容 API 的服务商、地址、模型和 Key；界面显示翻译进度及服务返回的 Token 用量。

THE READER

熟悉的论文，
更顺手的读法。

左侧整理文献和文件夹，右侧阅读原文、译文或对照。翻页与缩放同步，文字可选、可高亮、可下划线。

阅读界面示意
GET STARTED

安装后，三步开始阅读。

01 / 安装

下载 Windows 安装包

从 GitHub Releases 获取 Windows 64 位版本。首次启动需要 WebView2 运行时。

02 / 设置

配置翻译服务

在应用中保存兼容 API 的服务商、地址、模型和 Key，并用“测试连接”确认配置。

03 / 阅读

选择本机 PDF

通过系统文件窗口导入论文，可先读原文，再选择试译页码或翻译全文。

论文、批注和 API 设置保存在本机；实际翻译时，论文文字会发送至你配置的 API 服务。翻译可能产生服务商费用。中文文字长度、字体和换行会影响局部排版。
FAQ

你可能想了解的。

扫描 PDF 可以翻译吗？

主要面向包含文本层的 PDF。扫描件需要先经过 OCR，识别质量会影响后续翻译。

复杂表格能导出成 Markdown 吗？

复杂表格、跨页布局和特殊字体可能需要手动整理，Markdown 不能完整表达所有 PDF 排版。

模型调用会产生费用吗？

paper2zh 不替你提供模型额度。费用和限额由你配置的 DeepSeek 或兼容 API 服务商决定。

论文内容会发到哪里？

实际翻译的文字会发送给你配置的 API 服务；请阅读对应服务商的条款并自行判断适用性。API Key 在本地保护，但仍应妥善管理设备与密钥。

它是完全离线软件吗？

不是。阅读和本地管理可在设备上完成，但翻译需要访问你配置的 API，首次安装也可能需要网络。

从哪里查看源码和版本？

可前往 GitHub 源码仓库，或直接查看 最新发行版。
